I build **intelligent systems**, not isolated models.

My work focuses on designing architectures where autonomous agents can **reason, plan, retrieve knowledge, collaborate, simulate environments, and continuously improve**.

Rather than optimizing for benchmarks alone, I'm interested in creating systems that are:

- 🧠 Explainable

- 🌐 Distributed
